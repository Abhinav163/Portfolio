## 📖 About

This portfolio website serves as a comprehensive showcase of my professional journey as a Software Developer Engineer. It highlights my technical expertise, work experience, educational background, and personal projects. The website is designed with a clean, modern interface that provides an engaging user experience across all devices.

## ✨ Features

- **Responsive Design** - Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Smooth Navigation** - Sticky navigation bar with smooth scroll functionality
- **Interactive UI** - Modern and intuitive user interface with smooth transitions
- **Contact Form** - Integrated contact form using Formspree for direct communication
- **Resume Download** - Quick access to downloadable resume
- **Social Media Integration** - Direct links to professional social profiles (LinkedIn, GitHub, Twitter)
- **Project Showcase** - Dedicated section highlighting key projects
- **Copy-to-Clipboard** - Quick copy functionality for email and phone number
- **Skills Visualization** - Progress bars displaying proficiency in various technologies

## 📦 Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/Abhinav163/Portfolio.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd Portfolio
   ```

3. **Open in browser**
   - Simply open `index.html` in your preferred web browser
   - Or use a local development server:

     ```bash
     # Using Python
     python -m http.server 8000

     # Using Node.js (http-server)
     npx http-server
     ```

4. **Access the website**
   - Open `http://localhost:8000` in your browser

## 🎨 Customization

To customize this portfolio for your own use:

1. **Update Personal Information**
   - Modify content in `index.html`
   - Replace profile image in `assets/imgs/`
   - Update resume link and file

2. **Modify Styles**
   - Edit `assets/css/Style.css` for custom styling
   - Adjust color scheme and layouts

3. **Add/Remove Sections**
   - Edit the HTML structure in `index.html`
   - Update navigation links accordingly

4. **Configure Contact Form**
   - Replace Formspree endpoint in the form action attribute
   - Sign up at [Formspree](https://formspree.io/) for your own form endpoint
